# 作品集与面试表达

## 简历项目名

基于 YOLO11 的晴天夜间车辆检测与 Hard Negative Mining 误检抑制

GitHub: `https://github.com/EdgarWyq/vehicle-detection-domain-adaptation`

## 简历一句话

基于 YOLO11s 构建晴天夜间车辆检测模型，针对夜间灯光、屋顶和反光导致的大框误检问题，引入无车辆 hard-negative 样本进行对比实验，在相同训练配置下提升 Precision、Recall 和 mAP 指标，并完成数据检查、训练、验证、预测可视化和实验报告的工程化闭环。

## 简历项目描述

- 基于 ICDEC 车辆检测数据集抽取 Sunny/Night 子集，构建 15 类车辆检测实验流程。
- 使用 YOLO11s、`imgsz=960`、无图像增强设置训练 baseline，定位夜间大框误检问题。
- 采集 12 张无车辆夜间 hard-negative 图片，构造 60 张空标签训练样本，用于压制夜间背景误检。
- 设计严格对比实验，保持模型、输入尺寸、训练参数和验证集一致，仅改变训练集是否包含 hard-negative。
- 实验结果显示 hard-negative 版本在 Precision、Recall、mAP50 和 mAP50-95 上均优于 baseline，并通过可视化分析解释误检和漏检同时减少的原因。
- 封装数据检查、split 生成、训练、验证、预测和结果对比脚本，形成可复现工程项目。

## 面试可讲思路

面试官问“你做了什么”时，可以按这个顺序讲：

1. 我先跑通了 YOLO 车辆检测，但在 Sunny/Night 场景发现明显的大框误检。
2. 我没有直接调阈值，而是分析误检来源，发现主要来自夜间背景：屋顶、反光、灯光和暗部纹理。
3. 我采集了无车夜间 hard-negative 样本，标签为空，让模型学习这些背景不是目标。
4. 为了验证有效性，我做了 baseline 对比实验，保证模型和训练参数一致，只改变训练集。
5. 最后 hard-negative 版本不仅 Precision 提升，Recall 也提升；我的理解是背景 objectness 下降后，NMS 对真实小目标的干扰减少。

## 可能被追问的问题

### 为什么空标签图片能训练检测模型？

YOLO 会在每张图上学习大量背景位置的 objectness。空标签图片会告诉模型整张图都是背景，因此能降低相似背景区域的目标置信度。

### 为什么减少误检还能减少漏检？

误检框会参与 NMS，也会和真实小目标竞争置信度。当背景大框被压低后，真实目标框更容易保留下来，所以漏检可能减少。

### 为什么不用简单提高 conf 阈值？

提高阈值只能后处理减少低分误检，但可能损失召回。hard-negative 是从训练阶段改善背景/目标区分能力，更根本。

### 为什么关闭图像增强？

这次实验目标是比较 hard-negative 的影响。关闭增强可以减少额外变量，让对比更干净。

### 复制 hard-negative 会不会过拟合？

有风险，所以我把它作为一次定向实验。后续可以做复制倍数消融，比较 1x、3x、5x、10x 对 Precision 和 Recall 的影响。
